# 📱 Diabetes_App_ACIF

Aplicación Android para el **monitoreo integral de la diabetes**, desarrollada como proyecto académico en la  
**Universidad Autónoma de Aguascalientes (UAA)** 🎓.  

Construida en **Kotlin** y **Java**, con integración de **Firebase** para notificaciones, base de datos y servicios en la nube.

---

## ✨ Características principales

| Funcionalidad | Descripción |
|---------------|-------------|
| 🩺 **Control de medicina** | Registro de medicamentos (nombre, dosis, horarios) con notificaciones automáticas y historial de cumplimiento. |
| 🍬 **Monitoreo de glucosa** | Registro manual de niveles, gráficas de tendencias y alertas configurables para valores fuera de rango. |
| 💓 **Presión arterial** | Registro de presión sistólica/diastólica con historial y visualización de indicadores normales/altos. |
| 🏃 **Actividades físicas** | Registro de ejercicios, duración e intensidad, con progreso semanal/mensual. |
| 📅 **Calendario** | Agenda integrada para citas médicas y recordatorios, sincronizada con notificaciones push. |
| 👤 **Perfil del usuario** | Datos personales básicos, configuración de objetivos y personalización de temas/notificaciones. |
| 🔥 **Sistema de rachas** | Contador de días consecutivos cumpliendo metas, motivación visual para hábitos saludables. |

## 📦 Instalación rápida

1. **Descargar el APK**  
   👉 [Diabetes_App_ACIF (APK)](https://www.mediafire.com/file/6xk00faee2fmum8/ACIF.apk/file)

2. **Permitir instalación de apps externas**  
   - Ve a **Configuración > Seguridad**.  
   - Activa **Permitir instalar aplicaciones de orígenes desconocidos**.  
   - Instala el archivo descargado en tu dispositivo Android.
